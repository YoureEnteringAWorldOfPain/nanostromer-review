FINAL NANOSTROMER SITE

Upload these items to the ROOT of your GitHub repository:
- index.html
- robots.txt
- sitemap.xml
- CNAME
- assets/  (folder containing message-01.webp through message-17.webp)

GitHub Pages should be set to:
Settings > Pages > Deploy from a branch > main > /(root)

The custom domain is already declared in the CNAME file as:
nanostromer.com

After upload, connect the GoDaddy DNS records to GitHub Pages, then enable HTTPS in GitHub Pages.
